# Previsión meteorológica

Previsión para puertos, fondeaderos, rutas de navegación e inspecciones subacuáticas. Pondera 7 modelos meteorológicos y 4 de oleaje (Open-Meteo), con Windy y Windguru integrados, y estima la visibilidad bajo el agua con datos satelitales de NOAA.

Abrí `index.html` en el navegador o usá la versión publicada con GitHub Pages.
